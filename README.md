# AI를 대하는 태도

AI에게 일을 맡기기 전에 사람이 먼저 세워야 할 기준을, 네 개의 방과 열두 장의 카드로 살펴보는 공개 웹 콘텐츠입니다.

## 구성

1. **운전석** — 주도권과 이해
2. **기준을 세우는 책상** — 목적 · 흐름 · 완료 기준
3. **손으로 확인하는 실험대** — 검증과 원인 찾기
4. **내 것으로 만드는 기록실** — 이해 · 재질문 · 기록 · 검토

각 방에는 세 장의 카드가 있으며, 전체 12개 레슨은 `AI를 대하는 태도` 통합 원고의 핵심을 공개 웹 경험에 맞게 압축했습니다.

## 기술 구조

정적 HTML, CSS, Vanilla JavaScript로 구성됩니다. 시작 → 진입 효과 → 관점의 방 → 카드 → 레슨의 hash route 흐름과 기기별 로컬 진행 기록을 제공합니다. 이 프로젝트는 AX_Lecture 엔진의 공개 가능한 UI 구조를 참고해, 학습 운영 기능·기존 강의 콘텐츠 없이 독립적으로 재구성했습니다.

## 로컬 실행

정적 서버로 프로젝트 루트를 열면 됩니다. 예: `python -m http.server 8000`
