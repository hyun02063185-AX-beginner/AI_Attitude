# AI Attitude Copy Polish Review

목표: 원고체 문장을, AI를 활용하는 실무자가 슬라이드를 보며 자연스럽게 따라갈 수 있는 강의 화법으로 바꾼다. 의미(Meaning)는 바꾸지 않고 화법(Voice)만 바꾼다.

판정 기준은 하나다 — **"강사가 이 문장을 강의실에서 그대로 말해도 어색하지 않은가?"**

## 전체 판정 요약

19개 슬라이드(+Opening/Closing 포함) 중 대부분의 **제목**은 이미 구체적 동사(정한다·눌러본다·좁힌다·검토한다·말해본다) 중심이라 자연스럽다. 문제는 소수의 지점에 집중돼 있었다:

1. **추상명사 + "이다" 정의문** — 캡션 2곳, Key Copy 1곳에서 "OO은 △△의 기준점이다" 식 사전적 정의문이 등장한다. 실제로는 아무도 이렇게 말하지 않는다.
2. **문어적 비유 단어** — "잣대"(literary, 구어에서 거의 안 씀)가 제목 1곳·캡션 1곳에 등장한다.
3. **명사 단독 제목** — 동사 없이 추상명사만으로 끝나는 제목이 1곳 있다("이해의 최소선").
4. 나머지는 이미 통과 — Opening 질문과 Closing 회수, "AI는 손을 돕고, 방향은 내가 정한다" 등 핵심 카피는 원래도 자연스럽고 이미지와도 잘 맞는다.

## 유지한 Key Copy

- Closing 전체 ("AI는 손을 돕고, 방향은 내가 정한다" + teaser) — Opening/Closing callback의 중심이라 그대로 둔다.
- 1-2 캡션 "AI는 손을 돕고, 방향은 내가 정한다." — Closing과 같은 문장을 미리 심어두는 의도적 반복이다.
- 2-8 quote "기대와 실제의 차이로 범위를 먼저 좁힌다." — 이미 구체적이고 캡션과 자연스럽게 겹친다.

## 삭제한 과장/추상 표현

- "목적은 모든 선택의 기준점이다." (캡션 + Key Copy 중복 사용) — 추상명사 정의문의 대표 사례.
- "흐름은 결과가 맞는지 비교하는 기준이다." — 같은 패턴.
- "목적 · 흐름 · 완료 기준이 검증의 세 잣대다." / 제목 "세 개의 잣대" — 문어체 비유 단어 "잣대" 제거.
- "정리본에는 항상 실제와 대조하는 마지막 눈이 필요하다." — 억지 비유("마지막 눈") 제거.
- 제목 "먼저 그려야 할 지도", "이해의 최소선" — 명사구·정의어 중심 제목을 동사문/질문으로 교체.

## 이미지 교체가 필요해 보이는 후보

없음. 12개 lesson 이미지는 모두 캡션이 가리키는 장면과 일치한다(운전석=주도권, 지도 테이블=흐름·기준, 돋보기=검증, 필기=기록 등). 이번 리뷰에서 이미지-문장 불일치 사례는 발견되지 않았다.
